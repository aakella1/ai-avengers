# RAG and Agents — class demos

Two self-contained demos, meant to be run stage by stage while you explain
them.

| Folder | Demo |
|--------|------|
| `RAG/` | A retrieval-augmented generation pipeline in six scripts — extract, chunk, embed, index, retrieve, generate |
| `Agents/` | An agent built on the AWS Strands SDK, with nine tools and a Streamlit chat UI |

Each folder has its own README with the commands and the teaching notes. Start
with `RAG/README.md`.

## Setup

Python 3.10 or newer.

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## API keys

Keys are read from `.env` files, which are **not** included in this bundle.
Create your own:

```bash
echo "OPENAI_API_KEY=sk-..."       > RAG/.env       # optional, see below
echo "ANTHROPIC_API_KEY=sk-ant-..." > Agents/.env
```

| Key | Needed for | Optional? |
|-----|------------|-----------|
| `ANTHROPIC_API_KEY` | RAG stage 6, and the whole agent demo | Required |
| `OPENAI_API_KEY` | RAG stage 3 with `--provider openai` | Optional — `--provider local` runs a free embedding model on your CPU instead |

RAG stages 1–5 need no Anthropic key at all. With `--provider local`, the
entire retrieval half of the demo runs offline and free, which is useful if
students are following along on their own laptops without accounts.

## Quick start

```bash
# RAG — build an index, then ask a question
cd RAG
python 01_extract.py && python 02_chunk.py
python 03_embed.py --provider local        # or: --provider openai
python 04_load_index.py
python 05_retrieve.py --index latest --query "What awards has he received?"
python 06_generate.py --index latest --query "..." --show-prompt

# Agent — terminal, then browser
cd ../Agents
python agent.py --demo
streamlit run chat_app.py
```

The agent's `search_documents` tool queries the index built above, so run the
RAG pipeline first if you want to demo the two together. That combination is
the most interesting part of the set — see `Agents/README.md` → *Agentic RAG*.

## Notes

- `RAG/data/` is not included — it is regenerated by stages 1–4 in under a
  minute. The first `--provider local` run also downloads a ~90MB embedding
  model.
- The two PDFs in `RAG/` are Wikipedia article exports, used as sample source
  documents.
